نعم، الفكرة واضحة، لكن النص يحتاج إلى ترتيب المتطلبات وفصل ما يخص الواجهة عن آلية التخزين والرفع إلى Hugging Face. كما أن هناك نقطة مهمة ناقصة: ماذا يحدث للجمل التي لم تُترجم بعد عند الحفظ.

يمكن صياغته هكذا:

مواصفات تطبيق إدارة وترجمة الجمل العربية إلى الحسانية

1. الصفحة الرئيسية

عند دخول التطبيق تظهر ثلاث بطاقات رئيسية:

1. الترجمة
2. الجمل الحرة
3. سؤال وجواب

في المرحلة الحالية نركز على تطوير بطاقة الترجمة.

⸻

2. قسم الترجمة

عند الدخول إلى قسم الترجمة تظهر لوحة تحكم تحتوي على:

الإحصائيات

عرض إحصائيات مختصرة مثل:

* إجمالي الجمل.
* عدد الجمل المترجمة.
* عدد الجمل التي لم تتم ترجمتها.
* عدد الجمل المرفوعة إلى Hugging Face.

قائمة الجمل

تظهر الجمل في جدول، وكل جملة تحتوي على:

الجملة العربية	ترجمتها بالحسانية	الحالة
الجملة العربية	الترجمة الحسانية	مترجمة
جملة أخرى	—	لم تُترجم

ويجب توفير إمكانية فلترة الجمل التي لم تتم ترجمتها بعد، حتى يستطيع المستخدم الوصول إليها وترجمتها بسهولة.

⸻

3. إضافة جمل جديدة

يوجد في أعلى الصفحة زر:

+ إضافة جمل جديدة

عند الضغط عليه تظهر مساحة لإدخال عدة جمل عربية دفعة واحدة.

يقوم المستخدم بلصق الجمل العربية بحيث تكون:

* كل جملة في سطر مستقل.

مثال:

المحكمة رفضت قبول شهادة الأخ لأنها تدخل ضمن الأشخاص الذين لديهم عداوة مباشرة مع الخصم
قضية إبطال وصية المتوفى تدخل ضمن الاختصاص الحصري لقضاء الأسرة هنا في العاصمة

بعد الضغط على زر إضافة، يقوم التطبيق تلقائياً بإنشاء سجل مستقل لكل جملة.

مثلاً:

الجملة العربية:
المحكمة رفضت قبول شهادة الأخ لأنها تدخل ضمن الأشخاص الذين لديهم عداوة مباشرة مع الخصم
الترجمة الحسانية:
[حقل فارغ لإدخال الترجمة]

وهكذا لكل جملة.

⸻

4. إدخال الترجمة

تتم إضافة الترجمة الحسانية يدوياً من خلال الحقل المخصص لكل جملة.

مثال:

العربية:
المحكمة رفضت قبول شهادة الأخ لأنها تدخل ضمن الأشخاص الذين لديهم عداوة مباشرة مع الخصم
الحسانية:
المحكمة آبات تقبل شهادة الأخ بيه عنو داخلة الناس الي عندهم عداوة مباشرة مع الخصم

يمكن أن تبقى بعض الجمل بدون ترجمة، ولا يجب إجبار المستخدم على ترجمتها قبل حفظ البيانات.

⸻

5. الحفظ والرفع إلى Hugging Face

عند الضغط على زر حفظ:

يقوم التطبيق بالخطوات التالية:

أولاً: حفظ البيانات

يتم حفظ جميع الجمل في قاعدة البيانات، سواء كانت:

* مترجمة.
* غير مترجمة.

وذلك حتى لا تضيع الجمل التي أُضيفت ولم تتم ترجمتها بعد.

ثانياً: تجهيز بيانات Hugging Face

عند تجهيز البيانات للرفع إلى Hugging Face، لا يتم إرسال الجمل غير المترجمة.

أي أن السجل لا يدخل في Dataset إلا إذا كان يحتوي على:

arabic
hassani

وكان الحقلان غير فارغين.

مثال:

{"arabic": "المحكمة رفضت قبول شهادة الأخ لأنها تدخل ضمن الأشخاص الذين لديهم عداوة مباشرة مع الخصم", "hassani": "المحكمة آبات تقبل شهادة الأخ بيه عنو داخلة الناس الي عندهم عداوة مباشرة مع الخصم"}

أما هذا:

{"arabic": "جملة لم تتم ترجمتها بعد", "hassani": ""}

فلا يتم رفعه إلى Hugging Face.

⸻

6. صيغة البيانات

قبل رفع البيانات إلى Hugging Face يتم تحويلها تلقائياً إلى صيغة JSONL.

كل سطر يمثل مثالاً واحداً:

{"arabic": "المحكمة رفضت قبول شهادة الأخ لأنها تدخل ضمن الأشخاص الذين لديهم عداوة مباشرة مع الخصم", "hassani": "المحكمة آبات تقبل شهادة الأخ بيه عنو داخلة الناس الي عندهم عداوة مباشرة مع الخصم"}
{"arabic": "قضية إبطال وصية المتوفى تدخل ضمن الاختصاص الحصري لقضاء الأسرة هنا في العاصمة", "hassani": "قضية إبطال وصية المرحوم داخلة نقر التخصص الحصري لقضاء الأسرة هون فالعاصمة"}

⸻

7. دمج البيانات القديمة والجديدة

يجب الحفاظ على آلية السكريبت السابقة، بحيث لا يتم استبدال Dataset القديمة بالبيانات الجديدة فقط، وإنما يتم:

1. تحميل Dataset الموجودة حالياً على Hugging Face.
2. تحميل الترجمات الجديدة.
3. دمج البيانات القديمة والجديدة.
4. إزالة التكرارات.
5. إنشاء Dataset نهائية.
6. رفع Dataset النهائية إلى نفس المستودع:

ahmed200512/hassanie_claude-translation

ويجب اعتبار السجل مكرراً عندما يتطابق:

arabic + hassani

مع سجل موجود مسبقاً.

السكريبت الحالي الذي كان مستخدماً:

from datasets import load_dataset, Dataset
# تحميل الداتا القديمة
old_ds = load_dataset(
    "ahmed200512/hassanie_claude-translation",
    split="train"
)
# تحميل الداتا الجديدة
new_ds = load_dataset(
    "json",
    data_files="dataset.jsonl",
    split="train"
)
seen = set()
merged = []
# معالجة الداتا القديمة
for row in old_ds:
    arabic = row["arabic"].strip()
    hassani = row["hassani"].strip()
    key = (arabic, hassani)
    if key not in seen:
        seen.add(key)
        merged.append({
            "arabic": arabic,
            "hassani": hassani
        })
# معالجة الداتا الجديدة
for row in new_ds:
    arabic = row["arabic"].strip()
    hassani = row["hassani"].strip()
    key = (arabic, hassani)
    if key not in seen:
        seen.add(key)
        merged.append({
            "arabic": arabic,
            "hassani": hassani
        })
final_ds = Dataset.from_list(merged)
print("القديم:", len(old_ds))
print("الجديد:", len(new_ds))
print("بعد حذف التكرار:", len(final_ds))
final_ds.push_to_hub(
    "ahmed200512/hassanie_claude-translation"
)
print("تم الرفع بنجاح")

لكن السكريبت النهائي للتطبيق يجب تعديله بحيث لا يعتمد على ملف dataset.jsonl ثابت، وإنما يقوم التطبيق نفسه بتجهيز بيانات JSONL من قاعدة البيانات، ويأخذ فقط السجلات التي تحتوي على ترجمة حسانية.

⸻

8. قاعدة مهمة جداً

هناك فرق بين بيانات التطبيق و بيانات Dataset الموجودة على Hugging Face:

قاعدة بيانات التطبيق

تحتوي على جميع الجمل:

* المترجمة.
* غير المترجمة.

وذلك لإدارة عملية الترجمة ومتابعتها.

Hugging Face Dataset

تحتوي فقط على الجمل المكتملة:

Arabic + Hassani

ولا تحتوي أبداً على جملة عربية بدون ترجمة.

وبذلك يمكن للمستخدم إضافة 1000 جملة عربية مثلاً، ثم ترجمة 50 منها فقط.

في قاعدة بيانات التطبيق:

1000 جملة موجودة، منها 50 مترجمة.

أما Hugging Face:

50 جملة فقط.
